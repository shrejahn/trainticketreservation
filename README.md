#  Train Reservation System

A console-based Train Reservation System developed using **Core Java**.

##  Features

* Customer registration
* View available trains
* Search trains by train number
* Book train tickets
* Check seat availability
* Calculate ticket fare automatically
* Generate unique transaction ID
* View reservation history
* Cancel train tickets
* Restore seats after cancellation

##  Technologies Used

* Java
* Object-Oriented Programming
* ArrayList
* Exception Handling
* Java Date & Time API
* UUID

##  How to Run

1. Clone the repository.
2. Open the project in Eclipse, IntelliJ IDEA, or VS Code.
3. Compile the Java files.
4. Run `Main.java`.
5. Follow the options displayed in the console.
